How to read this dashboard

This dashboard looks at past credit-card customers and uses a computer model to estimate how likely each customer is to miss next month's payment.

Cards marked WHAT HAPPENED count what really happened. Cards marked ESTIMATE are the model's guesses. Hover over any i for a short explanation. Start with the Summary page and read the "In short" box at the top of each page.
